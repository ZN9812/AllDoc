# 디자인 메모

화면의 모양과 규칙을 한 곳에 모은 문서입니다. 값은 `web/src/styles/tokens.css`가 기준입니다.

## 방향

업무 앱. 첫 화면은 "파일을 올려 바로 고친다"에 집중하고, 장식보다 **읽기 쉬운 글씨, 분명한 단추, 예측 가능한 동작**을 우선합니다.
홈은 왼쪽 메뉴(새 문서·내 문서·설정), 큰 점선 상자, 최근 문서만 둡니다.

## 편집 화면

```
┌──────────────────────────────────────────────────────────────┐
│ 위쪽 바: 문서 이름 · 저장 상태      내려받기 · 야간 모드 · 로그인 │
├──────────────────────────────────────────────────────────────┤
│ 도구줄 (형식마다 자기 도구를 넣는다)                              │
├──────┬────────────────────────────────────────┬──────────────┤
│ 쪽   │            문서                         │ AI 대화       │
│ 목록 │                                        │ 서식 점검     │
│      │                                        │ 변경 내역     │
└──────┴────────────────────────────────────────┴──────────────┘
```

- 한글(HWP·HWPX)과 Word(DOCX)는 각 편집기가 자기 도구줄·메뉴를 그립니다. 우리는 그 위에 오른쪽 탭 3개만 얹습니다.
- **휴대폰(700px 이하)**: 문서가 화면 폭 전체를 쓰고, 쪽 목록은 숨고, 탭 창은 아래 막대의 단추로 아래에서 올라옵니다.
  Word 문서는 화면 폭에 맞춰 쪽을 줄여 보여 줍니다(확대하려면 브라우저 확대를 쓰세요).
- 화면 폭이 920px 이하면 쪽 목록을 접습니다.

## 색

- 기본은 밝은 관공서 청색(`--accent #1f5fd1`). 야간 모드는 어두운 작업 화면(`--accent #6aa5ff`).
- 설정: "밝게 / 어둡게 / 기기 설정 따르기"(기본 "밝게"). 첫 화면이 깜박이지 않도록 `public/theme-init.js`가 저장된 설정을 앱보다 먼저 적용합니다.
- **문서 종이는 두 테마 모두 밝게** 둡니다(인쇄물과 같은 모습으로 보이도록).
- **AI가 고친 곳은 두 테마 모두 청록색**(`--ai`, `--ai-bg`, `--paper-ai-bg`)으로 통일합니다. 파란색은 화면당 채운 단추 하나(주요 동작)에만 씁니다.
- 한글·Word 편집기에도 색을 맞춥니다(한글 편집기는 저장된 화면 색 설정을 읽어 열리고, Word 편집기는 `--sd-ui-*` 변수를 우리 토큰에 연결합니다).

## 글자와 모양

- 글꼴: Noto Sans KR(가변 글꼴, 앱에 포함). 문서 글꼴이 사용자 컴퓨터에 없으면 대체 글꼴로 보입니다.
- 모서리 8px(`--radius`), 작은 요소 5px. 단추 높이는 휴대폰에서 36px 이상(손가락으로 누르기 쉽게)으로 시험합니다.
- 움직임은 `prefers-reduced-motion`을 따릅니다.

## 동작 규칙

- AI는 문서를 바꾸지 않고 **제안**만 합니다. 카드마다 적용 · 취소 · (적용 후) 되돌리기. 오래된 제안(제안을 만든 뒤 사용자가 그 문단을 고친 경우)은 적용하지 않고 이유를 알려 줍니다.
- 카드에 마우스를 올리면 문서 위에서 그 곳을 진하게 표시하고(TXT·MD·DOCX), "문서에서 보기"를 누르면 그 곳으로 이동합니다(TXT·MD·DOCX·HWP·HWPX).
  한글 편집기는 별도 화면(iframe)이라 문서 위에 겹쳐 표시하지 못해 카드로 확인합니다. 한글의 표 안 글은 "문서에서 보기"가 그 칸(표 안의 표 포함)으로 이동해 고칠 글을 선택합니다. 한글의 머리말·꼬리말·각주는 편집기가 그 자리로 바로 이동하지 못해, 그것을 넣은(단) 본문 문단으로 이동하고 "이 글은 각주 1에 있어요…"처럼 알립니다.
  Word 편집기가 그리는 쪽에 있는 머리말·꼬리말·각주·글상자는 문서 위에 강조하고 이동합니다. 쪽에 그리지 않는 곳(미주)과, 시험한 문서에서 강조하지 못한 표 칸 안의 글상자는 이동하지 못한다고(글상자는 몇 번째 글상자인지) 알립니다.
- 원본은 덮어쓰지 않습니다. 고친 문서는 `<이름>_수정본.<확장자>`로 내려받습니다.
- 자동 저장은 마지막 편집 0.8초 뒤, 이 브라우저(IndexedDB)에만 저장합니다. 저장 상태는 위쪽 바에 항상 보입니다.
- 서버에 연결할 수 없어도 편집은 되고, AI만 안내가 나옵니다.

## 이름과 로고

"AllDoc"은 임시 이름입니다. 이름·로고·색은 `web/src/brand/` 한 곳에서 바꿉니다. 공개 운영 전에 상표와 도메인을 확인하세요.
